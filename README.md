# Bharat Singh Lovewanshi — Portfolio

A responsive personal portfolio showcasing my skills, projects, and contact information, built using HTML, CSS, and JavaScript.

**Live Portfolio:** [bharatsingh22-portfolio.netlify.app](https://bharatsingh22-portfolio.netlify.app/)

**GitHub Repository:** [bharat-portfolio](https://github.com/Bharatlovewanshi/bharat-portfolio)

## Features

- Responsive design for desktop, tablet, and mobile.
- About, Skills, Projects, Resume, and Contact sections.
- Dark navy, blue, and cyan theme.
- Project and professional profile links.
- Resume access and email contact.
- Netlify Forms integration with input validation and spam protection.

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- Netlify Forms
- Git and GitHub
- Netlify

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Bharatlovewanshi/bharat-portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd bharat-portfolio
   ```

3. Open `index.html` using VS Code Live Server, or run:

   ```bash
   python -m http.server 8000
   ```

4. Visit http://localhost:8000.

## Contact Form

The contact form uses Netlify Forms and supports name, email, subject, and message fields.

To verify submissions, open the deployed website, submit a test message, and check **Netlify Dashboard → Forms → `portfolio-contact`**.

Local previews do not submit messages to Netlify.

## Deployment

The portfolio is hosted on Netlify and connected to GitHub for automatic deployments from the `main` branch.

Updates pushed to the connected repository trigger a new deployment.
